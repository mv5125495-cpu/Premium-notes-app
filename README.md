# Premium Notes

A beginner-friendly native Android notes app built with Kotlin, Jetpack Compose, and Material 3.

## Included

- Splash, login, and signup flows
- Home dashboard with local sample notes and categories
- Search, category filters, note details, and bookmarks
- Profile and settings screens with light/dark appearance
- Separate sample Admin Login and Admin Dashboard flows
- Admin sections for Users, Notes, Categories, and Announcements

## Build

Open the project in Android Studio with Android SDK 35 installed, then run:

```bash
./gradlew assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

This project uses only local sample data. No API keys, paid services, or copyrighted assets are required.
